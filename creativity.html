The Panel System 面板系统

Native scroll + snap, two axes: vertical between chapters, horizontal within them. 原生滚动 + 吸附，两个方向：章节间纵向滚动，章节内横向翻页。

  • scroll-snap-type: x mandatory — the browser does the physics — no carousel library. 物理效果全靠浏览器 —— 不用轮播库。
  • scroll-snap-align: start — every panel lands exactly where it should. 每个面板都精准停在该停的位置。
  • overscroll-behavior: contain — no accidental back-swipe, ever. 永远不会误触返回手势。

Principles 设计原则

  • Code is the aesthetic 代码即美学
    Monospace everywhere. The site reads like a well-formatted source file. 全站等宽字体。整个网站读起来像一份排版精良的源代码文件。
  • Cards, not pages 卡片，而非页面
    Soft borders, 12px radii, shadows that whisper. Content lives in cards. 柔和的边框、12px 圆角、若隐若现的阴影。内容都住在卡片里。
  • Motion earns its place 动效物尽其用
    Reveals, nudges, and bobs — always subtle, always skippable via reduced-motion. 渐显、轻推、浮动 —— 始终克制，且始终尊重减少动效偏好设置。
  • Zero frameworks 零框架
    Hand-written HTML/CSS/JS. Every byte on the page was put there on purpose. 纯手写 HTML/CSS/JS。页面上的每一个字节都有它存在的理由。

Cartography 地图绘制

Hand-drawn SVG maps from /maps — every coastline, peak, and ferry route is a path I plotted. 来自 /maps 的手绘 SVG 地图 —— 每一条海岸线、每一座山峰、每一条渡轮航线，都是我亲手绘制的路径。

Anatomy of a panel map 一幅面板地图的解剖

  1. A rotatable D3 globe greets you first — countries fill in as they're visited, cities pin with tooltips. 首先迎接你的是可旋转的 D3 地球仪 —— 到访过的国家逐一填色，城市图钉带有悬浮提示。
  2. Scroll down, and the world zooms in — a full-viewport Pacific Northwest chart snaps into place with a fade-and-rise reveal. 向下滚动，世界随之放大 —— 一幅满屏的太平洋西北地区海图以渐显上升的方式吸附就位。
  3. Swipe right for route charts — Salish Sea ferry crossings drawn like an old nautical map: anchors, whales, sea-siren medallions. 向右滑动查看航线图 —— 萨利希海的渡轮航线画成旧式航海图的模样：锚、鲸鱼、海妖徽章。
  4. Everything is inline SVG — no tiles, no map API. Peaks get elevation labels; unvisited ones fade back politely. 一切都是内联 SVG —— 没有瓦片，没有地图 API。山峰标注海拔；未到访的则礼貌地淡入背景。
  5. Dots, chevrons, and edge handles guide the way — the same navigation grammar reused across the whole site. 圆点、箭头和边缘把手指引方向 —— 与全站复用同一套导航语法。
